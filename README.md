# Survaivo Umrah SaaS

الطبقة الأساسية لإدارة شركات العمرة ومستخدميها. المشروع مستقل تمامًا عن مشروع `sa` المرجعي.

## النطاق الحالي

- Tenant مستقل لكل شركة.
- مستخدمون بعضويات وأدوار منفصلة.
- أدوار: مالك، مدير، مشرف، موظف، ومشاهد.
- دعوات قابلة للإلغاء وتنتهي بعد سبعة أيام.
- عزل كل عمليات القراءة والكتابة بواسطة `tenant_id` على الخادم.
- سجل أنشطة للتغييرات الحساسة.
- واجهة عربية متجاوبة للوحة الشركة والفريق والإعدادات.

## التشغيل

```bash
pnpm dev
pnpm test
pnpm build
```

المعاينة المحلية تستخدم بيانات تجريبية داخل الذاكرة. النسخة المنشورة تستخدم D1 والهوية الموثقة التي يمررها Sites، ولا تعتمد على بيانات المتصفح كمصدر للحقيقة.

## البنية

- `public/`: الواجهة العربية وتفاعلاتها.
- `worker/`: واجهات API والتحقق من الهوية والصلاحيات وعزل الشركات.
- `db/schema.ts`: مخطط Drizzle.
- `drizzle/`: ترحيل قاعدة البيانات.
- `scripts/`: تشغيل المعاينة وبناء حزمة النشر.
